This module enforces SC-12, SC-13, SC-28, AU-11, and CM-6 on a single GCS bucket. It creates a KMS keyring and customer-managed encryption key with 90-day automatic rotation, then provisions a storage bucket encrypted with that CMEK. The bucket enforces uniform bucket-level access, public access prevention, versioning, and a configurable retention policy. Four required compliance labels are hardcoded and cannot be overridden by consumers.
